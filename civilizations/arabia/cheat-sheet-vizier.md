## Identity

| | |
|---|---|
| **Civ ability** | The Last Prophet — guaranteed final Great Prophet |
| **Leader ability** | Righteousness of the Faith — Worship Building costs 90% less; provides +10% Science/Faith/Culture city-wide |

## Build Order (Capital)

```
Ancient:   Warrior/Slinger/Scout → Monument → Settler → [Shrine]
           (Warrior = safe default; Slinger for Archery Eureka; Scout on large/safe maps)
           Holy Site when Astrology Eureka fires (Natural Wonder discovered)
Classical: Shrine → Holy Site → Temple → [Settler for city 3]
Medieval:  Worship Building (1–3 turns! deploy immediately after founding)
           → Campus → Library → Madrasa (faith-purchase via Jesuit Ed.)
```

## Mamluk Notes

- Heals: 20 HP/turn in city centers, 15 in friendly, 10 neutral, 5 hostile
- Build in: highest-Production city with Horses accessible
- Keep 4–6 active from T90 onward
- Upgrade path: Mamluk → Cavalry → Mechanized Infantry

## Religious Victory Checklist

```
[ ] Tithe founder belief (Gold scaling)
[ ] Jesuit Education follower belief (faith-buy Madrasas)
[ ] Hagia Sophia wonder (extra Missionary spreads + Apostle promotion)
[ ] 5+ active Missionaries/Apostles from T120
[ ] Open Borders with civs you need to convert
[ ] Proselytizer Apostles for stubborn cities
[ ] 51% of rival cities = win
```

## When Things Go Wrong

| Problem | Fix |
|---------|-----|
| No good Holy Site placement | Target +2 minimum; next city should compensate |
| Jesuit Education taken | Build Madrasas via Production; faith-buy other buildings |
| Rival religion in your cities | Apostle (Proselytizer) + Inquisitor on your border |
| No Horses | Trade for them; pivot to Crossbowmen if unavailable |
| Behind on Science | Prioritise Madrasa and Research Labs via faith-purchase |
| Stuck at 48% Religious | Proselytizer wave + Open Borders negotiations |
